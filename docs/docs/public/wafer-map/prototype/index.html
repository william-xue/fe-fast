操作与实现
模拟数据

1. 拖动改变画面偏移，滚轮改变缩放比例；缺陷的数据坐标不变。

2. 低倍率我不画点，用 512² 密度图聚合；高倍率才逐点绘制，并且只画视口内的点。这叫 LOD + 视口裁剪。

3. 数据不进 Vue 响应式：TypedArray 存坐标和分类，Die 用 ix/iy 直接寻址，悬停 O(1)，不扫全量。

4. 所有数据均在本地模拟生成；不包含真实检测文件、后端查询或生产良率结论。

Canvas 实现与边界
  • TypedArray 数据层：Float32Array 存坐标，Uint8Array 存分类，Int32Array 存 Die 索引，避免逐条创建缺陷对象。
  • LOD：低倍率用 512² 密度图，高倍率才逐点绘制；缩放阈值切换，避免「一上来就画 100 万个点」。
  • 视口裁剪：遍历缺陷，仅绘制屏幕范围内的点；单帧绘制有上限，达到上限时不代表完整展示。
  • 空间索引：Die 用 ix/iy 直接寻址，O(1) 命中；缺陷汇总到 Die，悬停不扫全量。
  • 按需渲染：没有持续 rAF 空转，只有数据/视口/交互变化才重绘。
