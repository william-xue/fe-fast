## 我的判断

大多数「图形卡顿」不是渲染的问题，是数据和管线怎么组织的问题。选错了层，后面所有优化都白做——所以我做的第一件事永远是定位，不是表态。

AI 也一样。一个能回答问题的模型不值钱，值钱的是它出错的时候，系统知道该怎么办。
