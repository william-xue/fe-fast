## How I think about it

Most "graphics jank" is not a rendering problem — it is a problem of how the data and the pipeline are organised. Pick the wrong layer and every later optimisation is wasted. So the first thing I do is always diagnose, not opine.

The same goes for AI. A model that can answer a question is not worth much. What is worth something is a system that knows what to do when the model gets it wrong.
