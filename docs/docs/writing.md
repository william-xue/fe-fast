## 写给程序员的电力系统去魅指南

这是我最想让人看到的一组文章。起因很简单：我做了几年电力行业软件，发现**这个行业里既懂电力又能给程序员讲清楚的人非常少**；反过来，程序员想进这个行业，通常第一道墙不是编程，而是"这些人在说什么"。

这组文章就是拆这道墙的：从电网是并发数据流讲起，一路讲到拓扑、潮流计算、优化器约束、SCUC 跑通，最后讲行业生态与个人的位置。
